# 内容区（页面/内容区）

sing-box-for-apple 新 UI 的四个顶部卡片对应的内容区视图。

## 当前阶段

**骨架阶段（数据待对接）**

- 仅保留 UI 结构与视觉样式，全部使用静态占位数据。
- 不依赖 new-vpn 项目的任何数据层（节点管理器、策略组管理器、网络活动管理器、测速服务、隧道管理器等）。
- 统一通过 `@EnvironmentObject var 状态: 新UI状态` 读取全局 UI 状态。
- 所有数据接入点均标注 `// TODO: 第六阶段对接官方 CommandClient 数据`。

## 文件清单

| 文件 | 视图结构体 | 说明 |
|---|---|---|
| `节点内容区.swift` | `节点内容区` | 搜索栏 + 可展开节点分组列表 + 节点双卡片（名称/协议/地址/延迟徽章/选中态），右侧长按测速骨架 |

| `规则与日志内容区.swift` | `规则与日志内容区` | 顶部横向日志级别筛选胶囊（全部/追踪/调试/信息/警告/错误/致命）+ 单色日志列表（级别圆点 + 模块 + 时间 + 消息） |

## 依赖

- 设计令牌：`../设计系统/UIConst.swift`（颜色 `主题色/成功色/警告色/危险色/次要文字/页面背景/卡片背景/分割线`、间距 `间距常量`、圆角 `圆角常量`、动画 `动画常量`、字体）。
- 全局状态：`../状态/新UI状态.swift`（`新UI状态`，已提供 `是否已连接` 等桥接属性）。
- 空状态组件：`../组件/EmptyStateView.swift`（视图名 `EmptyStateView`，由基础组件任务创建，初始化参数：`图标:String, 标题:String, 说明:String`）。

## 占位数据

每个文件内部 `private struct` 定义了 3–5 条示例数据：

- 节点内容区：3 个订阅分组（香港/日本/美国），共 9 个节点。
- 策略组内容区：3 个策略组（selector/urltest/fallback）。
- 网络活动内容区：5 条 TCP/UDP 连接记录。
- 规则与日志内容区：10 条不同级别日志。

## 后续阶段（第六阶段）对接点

1. 用官方 `CommandClient` 返回的真实模型替换 `占位节点项 / 占位策略组 / 占位连接记录 / 占位日志项`。
2. 节点卡片点击 → 调用 `新UI状态.切换节点(...)` 或 ExtensionProfile 接口。
3. 测速按钮 → 对接官方延迟测试 API。
4. 网络活动列表 → 订阅 CommandClient 的连接事件流。
5. 日志列表 → 订阅官方日志推送，并接入环形缓冲区（参考 `全局常量.日志缓冲条数`）。
